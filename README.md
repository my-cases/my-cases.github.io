# FORMA — сайты и приложения под ваши задачи

Статический адаптивный сайт разработчика сайтов, систем управления и приложений для образования, бизнеса и других сфер. Школьные проекты показывают примеры возможностей; первый экран и контакты объясняют, что можно заказать решение под любую задачу.

## Структура

- Первый экран: что делает FORMA и как связаться.
- Три предложения с понятными задачами и результатами.
- Четыре реальных проекта: учебное приложение, две системы управления и электронный журнал. По нажатию открываются видео или изображение интерфейса.
- Три этапа работы и ответы на вопросы о стоимости, сроках и начале проекта.
- Контакт в WhatsApp с необязательным полем для описания задачи.

## Локальный просмотр

Откройте `index.html` в браузере или запустите:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Адрес: `http://localhost:4173`.

## Контакты и материалы

Получатель WhatsApp: `79898953970`. Номер указан в `data-whatsapp-number` тега `<body>`, в ссылках `https://wa.me/…`, атрибуте `action` формы и видимом контакте в `index.html`. При смене номера обновите все эти места, чтобы ссылки работали и без JavaScript.

Кнопки открывают WhatsApp с готовым текстом. Отправку подтверждает сам посетитель в чате. Имя и описание задачи не обязательны. Сервер для обработки формы не нужен.

Изображения и видео лежат в `assets/`. Видео загружаются только при открытии просмотра и запускаются посетителем. Шрифты локальные; внешние библиотеки для страницы не нужны.

`build_catalog.py` и `catalog_extra.py` относятся к предыдущей версии каталога и для новой страницы не используются.

Публичный адрес: https://my-cases.github.io/. Сайт публикуется через GitHub Pages из ветки `main` репозитория `my-cases/my-cases.github.io`. Локальные изменения сами по себе не обновляют публикацию.

При обновлении CSS и JavaScript меняйте параметр `v` у ссылок на эти файлы в `index.html`, чтобы браузеры загрузили новую версию.
