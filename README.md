# FORMA — каталог цифровых решений

Статический адаптивный сайт для образовательных проектов. Каталог в правой части первого экрана содержит 16 ролей и типов школ, 418 проблем и конкретных решений. Раздел кейсов показывает учебное приложение, две CRM и онлайн-журнал.

Публичный адрес: https://my-cases.github.io/

Для локального просмотра откройте `index.html` в браузере или запустите сервер:

```powershell
python -m http.server 4173 --bind 0.0.0.0
```

После запуска сайт доступен по адресу `http://localhost:4173`.

Чтобы открыть сайт на телефоне в той же Wi‑Fi-сети, используйте адрес `http://<локальный-IP-компьютера>:4173/`.

## Каталог и заявки

- Дополнительные задачи хранятся в `catalog_extra.py`. После правок выполните `python build_catalog.py`, чтобы обновить HTML и счётчики.
- Изображения кейсов лежат в `assets/case-*.webp` и `assets/case-crm-green.jpg`; видео приложения, синей CRM и журнала открываются по нажатию «Смотреть демо». Видео загружаются только при открытии.
- Получатель WhatsApp задан в атрибуте `data-whatsapp-number` тега `<body>` в `index.html`: `79898953970`.
- Кнопка открывает WhatsApp с готовым сообщением от посетителя. Посетитель нажимает «Отправить» в своём WhatsApp. Сайт не может отправить сообщение от номера посетителя без его подтверждения; WhatsApp Business API отправляет сообщения от подключённого бизнес-номера, а не от номера посетителя.

Шрифты лежат в `assets/`; для отображения страницы внешние сервисы не требуются.
